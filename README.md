# BakeryStore - автоматизована інформаційна система управління замовленнями в пекарні-кондитерській


## Ролі та основні можливості системи

### Касир:
* Авторизація в системі та керування робочою зміною (відкриття/закриття, нульовий чек, формування **Z-звітів**)[cite: 5, 21].
* Швидке оформлення замовлень за допомогою пошуку товарів за назвою чи кодом[cite: 5, 27].
* Розрахунок загальної суми та решти (підтримка готівкової та безготівкової оплати)[cite: 11, 27].
* Керування статусами поточних замовлень (*«Готується»* / *«Завершено»*) та перегляд їх детального складу[cite: 5, 11].
* Перегляд історії здійснених продажів і контроль залишків на складі[cite: 5, 9].

### Адміністратор:
* Перегляд фінансової звітності та аналітики продажів за обраний період (Z-звіти)[cite: 6, 31].
* Керування обліковими записами касирів (додавання, видалення, зміна логінів та паролів)[cite: 6, 22].
* Керування асортиментом складу (додавання нових товарів, редагування цін, кількості та категорій)[cite: 6, 22].

### Стек технологій

* **База даних:** SQLite (файлова БД `bakery_db.db`)
* **Мова програмування та платформа:** C#, .NET Framework 4.7.2
* **Клієнтська частина (Desktop UI):** WPF (Windows Presentation Foundation), XAML, Material Design In XAML Toolkit (MaterialDesignThemes 4.5.0), Microsoft.Xaml.Behaviors.Wpf
* **Доступ до даних:** Entity Framework 6 (авторизація користувачів), ADO.NET / System.Data.SQLite (замовлення, склад, зміни, звіти)
* **Архітектура:** багатовіконний десктопний застосунок з розподілом за ролями (Касир / Адміністратор)
* **Інструменти розробки та моделювання:** Visual Studio, DB Browser for SQLite, NuGet, Git / GitHub
